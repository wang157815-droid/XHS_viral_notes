# 爆文分析系统 - 安全升级通知

**更新日期**: 2025年12月

---

## 改了什么

**系统现在需要登录才能使用。**

---

## 你需要做什么

1. 启动系统后，**记下命令行显示的初始密码**（只显示一次）
2. 打开网页，用 `admin` + 初始密码登录
3. **必须修改密码**后才能使用其他功能
4. 以后每次使用都需要登录

---

## 为什么要改

保护你的小红书 Cookie 不被他人看到或盗用。

---

## 常见问题

| 问题 | 解决 |
|------|------|
| 忘记密码 | 联系技术重置 |
| 提示"请重新登录" | 正常，重新登录即可 |
| 看不到 Cookie 内容了 | 正常，安全考虑不再展示明文 |
