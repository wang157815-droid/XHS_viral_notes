📌 技术栈与调用链路
后端框架： FastAPI Python 3.10+ asyncio
AI模型： DeepSeek Qwen3-VL GLM-4
存储： JSON文件 ChromaDB Excel
加密： execjs Node.js
完整调用链： 用户输入 → FastAPI路由 → BackgroundTask → ViralCollector(XHS API) → FeatureExtractor → KnowledgeRetriever(JSON+RAG) → ViralAnalyzer(LLM) → SynthesisService → ExportService → Excel/JSON输出
