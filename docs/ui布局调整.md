一、UI 问题
（一）整体布局
首页
采用“侧边栏布局”，也即左侧为侧边导航栏，右侧为核心操作区。
1）左侧：侧边导航栏
（1）作用：提供全局导航和上下文定位，让用户随时知道自己在哪里，并能快速切换不同模块。
（2）宽高：259×  761 px（不含底部“设置中心”：259 × 65 px）
2）右侧：核心操作区
（1）作用：承载核心业务逻辑和用户交互，是用户停留时间最长的地方。
    a. 上部：核心操作区（这里是主输入框“洞见爆文规律，开启灵动创作”），这是整个页面的视觉重心，引导用户立即开始行动。
    b. 中部/下部：内容展示区，以卡片网格形式展示“最佳实践”。
（2）宽高：
    a. 操作区·输入框
  • 宽高尺寸：755 ×  55 px
  • 输入框位于页面中的位置：输入框上沿距离页面顶部 346px；输入框下沿距离页面底部 422px；输入框左侧顶点距离左左侧边栏右侧分界线241px；输入框右侧顶点距离右侧边线 241px。
  • 输入框距离“内容展示区”距离：25px
    b. 操作区·页面尺寸
  • 宽高：1252 × 827 px

2. 洞察分析执行页
1）启动分析后，输入框垂直平滑移至操作区底部
（1）位置：输入框下沿边线距离页面底端 32px，距离页面顶端 740px。
（2）在输入框下沿边线与页面底端之间加入“内容由AI生成，可能有误，请注意核查”的中文字体，字体颜色为：#8c8c8c，字号大小为：12px。
2）页面布局
整体页面布局基于渐进式披露原则，设计的动态三栏布局。它默认呈现为双栏的主从视图，当任务执行完成，用户与中间的Agentpanel进行交互，点击输出结果时，页面会平滑过渡并展开右侧的详情预览窗格，从而形成三栏结构。
在三栏式布局中，两个面板之间可交互的“边界线”，采用“分隔器控件”，支持用户调整三栏布局的大小，赋予用户“布局控制权”，让不同需求的用户都能找到最舒服的阅读和工作比例。
（1）左侧边栏宽度尺寸限定
  • 最宽：400px
  • 最窄：240px
（2）Agentpanel 宽度尺寸限定
  • 最宽：768px
  • 最窄：300px
（3）预览区宽度尺寸限定
  • 最宽：973px
  • 最窄：504px

（三）字体方案（参考）
字体家族 (Font Families)
本项目在src/index.css中定义了全局变量，确保在不同语境下实现最优的阅读体验：
1）正文 UI (Sans-serif):
使用 Inter 作为首选，兼容 PingFang SC (苹方) 以确保中文界面的极致清晰度。
变量名:--font-sans
字体栈:"Inter", "Helvetica Neue", "PingFang SC", ui-sans-serif, system-ui
2）标题与重点 (Serif):
采用 Playfair Display，配合 Source Han Serif SC (思源宋体) 提供 editorial (杂志感) 的优雅与沉稳。
变量名:--font-serif
字体栈:"Playfair Display", "Georgia", "Source Han Serif SC", serif
3）代码/日志 (Monospace):采用 JetBrains Mono，维持极客的高代码密度与可读性。
变量名:--font-mono
字体栈:"JetBrains Mono", ui-monospace, SFMono-Regular, monospace

2. 字号与字重 (Sizing & Weight)
UI 严格遵循响应式设计的“克制”原则，通过 Tailwind 工具类进行精确控制：
1）微标注/日志 (Small/Utility):text-xs (常用于步骤详情、Metadata)
2）基础交互 (Base UI):text-[13px] 或 text-sm (用于标签、按钮、正文交互)
3）标题 (Headings):全局 h1 - h6 均自动应用 Serif 家族，配合 font-light 字重，以减轻视觉重量，强调呼吸感。

3. 色彩映射 (Color Palette)
色彩系统以obsidian(黑曜石) 为支点，并辅以多种透明度实现视觉层次：
1）主文案:--color-obsidian (#1A1A1A) - 深度中性黑，提供极高对比度的阅读基准。
2）辅助/占位/次要:通过 Obsidian 的透明度衍生系列实现：
（1）text-[#1A1A1A]/60 (约 60% 透明度): 用于非活跃状态文本、次级提示。
（2）text-[#1A1A1A]/40 (约 40% 透明度): 用于极次要的指引、分割线信息。
