# 二、爆文模型结果呈现问题

## (一)爆文模型定义

1. 定义的核心:回答“爆文模型”是什么。
2. 定义的方法:采用“属加种差法”,并结合“操作性定义”的定义法,对爆文模型进行本质定义。

a. 核心方法:属加种差法(解决“是什么”的本质定性)
小红书爆文模型的邻近“属”概念非常明确,即“小红书爆款笔记内容的内容模型”。定义的关键在于提炼“种差”,即各类模型之间不可替代的独特性。规范定义公式:
[具体模型名称]是指以[特定呈现形式/情感载体]为手段,切中用户[核心心理动机/互动需求],从而在小红书平台获得高流量的内容模型。示例应用:
* 文艺抒情型:是指以文字/图文叙事或情绪渲染为手段(种差1),切中用户情感共鸣或审美向往(种差2)的小红书爆款笔记内容模型(属)。
* 痛点猎奇型:是指以反常规、高视觉冲击力的现象或观点为引子(种差1),直击用户现实焦虑或核心痛点(种差2)的小红书爆款笔记内容模型(属)。

b. 补充方法:操作性定义(解决“怎么判定”的执行定量)
如若在 Agent 或大模型的实际运行中,出现“文艺”、“猎奇”等抽象性词汇,则引入操作性定义,将概念转化为可观测、可提取的特征矩阵(Prompt 判定标准)。示例应用:

| 模型名称 | 属(分类) | 种差(本质特征) | 操作性定义(Agent 识别的特征指标) |
| :--- | :--- | :--- | :--- |
| 纯图抒情型 | 小红书爆款笔记模型 | 视觉为主,弱化文字,纯靠画面传递情绪。 | 1.封面及内页无任何牛皮癣文字<br>2. 笔记正文字数<50字,多使用表情符号;<br>3. 图片视觉风格统一(如日系、复古、冷淡风)。 |
| 颜值自用型 | 小红书爆款笔记模型 | 以高颜值场景/人物为第一视觉,结合真实自用体验种草。 | 1. 图片视觉主体为产品高颜值特写或人品合影;<br>2. 核心文案包含“无限回购”、“亲测”、“私藏”等第一人称真实体验词。 |

3. 呈现方式
  在sheet1“爆文总结”的每个爆文模型下,增加一行为:“模型定义”,对每个爆文模型进行概念阐释。

## (二)痛点问题描述

1. 描述的核心:定义痛点标签,抓住痛点背后的理论本质,并阐述痛点背后的用户核心诉求。
2. 描述的方法:运用社会科学专门理论框架,对痛点标签进行科学定义和阐释。
引入消费者行为学 (Consumer Behavior)、心理学和商业策略的成熟框架,对零散的“痛点标签”进行深度分析和定性描述—————不仅需要说明痛点的字面意思,更要自主检索并调用最适宜的消费者行为学、心理学等理论方法,直击痛点背后的底层本质与核心诉求。

**Output Framework(目标与产出标准)**
对于每一个痛点标签,必须自行选择最契合的1-2个底层理论,并严格按照以下结构进行分析(禁止泛泛而谈,必须直指业务价值):
a. 标签与频次:[痛点标签名称](频次)
b. 模型选用的理论/方法:[明确指出你选择了什么理论/方法,并用一句话说明为什么这个理论最契合该痛点]
c. 痛点科学定义(本质是什么):[结合所选理论,用严谨、学术且一针见血的语言定义该痛点]
d. 核心诉求阐述(在讲什么):〔还原用户的真实使用场景、心理障碍或情感动机,说明用户到底想要什么]

**Constraints (模型工作的约束条件)**
a. 理论适配性原则:必须根据数据类型自主选择最适宜的理论。例如:涉及成分、参数的选择困难优先选用有限理性/选择瘫痪/认知成本;涉及面子、人设的优先选用符号消费/自我概念;涉及功能错配的优先选用趋避冲突/Kano模型/JTBD。禁止千篇一律地套用同一个理论。
b. 惜字如金,直击根本:任何观点的提出必须有据可循。凡是一句话能讲清楚的案例和观点,绝不使用第二句话。用词必须专业、严谨、客观,体现专家级水准。

**Example(示例)**
【认知与决策障碍类(核心痛点:信息过载与选择瘫痪)】
·涉及标签:香水选择困难(8次)、选香困难(2次)、香水推荐(2次)
·对应理论:有限理性理论(Bounded Rationality)与选择矛盾(Paradox of Choice)。
·科学描述:这反映了用户在购买决策前期的**“信息搜寻与方案评估”障碍。香水作为一种高度主观、缺乏统一量化标准(看不到、摸不着)的商品,用户在面对庞大的气味市场时产生了认知过载**。他们缺乏将抽象气味(如前中后调)转化为个人风格匹配的能力,因此极度依赖外部“决策锚”(即爆款推荐)来降低决策成本。

**输出**
采用“痛点标签、出现频次、痛点本质定义、核心诉求阐释”的结构化格式,对痛点标签进行科学定义和诉求阐释,在sheet1的痛点标签区域增设“痛点本质定义”“核心诉求阐释”两列,呈现精简的文本内容。
